# Sons

Todos os sons vêm de dois pacotes de **Kenney** (www.kenney.nl), licença
**Creative Commons Zero (CC0 1.0)**: https://creativecommons.org/publicdomain/zero/1.0/

- "Casino Audio" (1.1): https://kenney.nl/assets/casino-audio
- "Interface Sounds": https://kenney.nl/assets/interface-sounds

Convertidos para mono 44,1 kHz com ffmpeg, em `.ogg` (Vorbis) e `.mp3`
(para navegadores sem Ogg). Alguns foram mixados.

| Arquivo | Uso | Origem |
|---|---|---|
| draw | comprar carta | Casino: card-slide-1 |
| flip | virar / espiar carta | Casino: card-place-1 |
| discard | descartar | Casino: card-place-2 |
| swap | cartas trocando de lugar (voo) | Casino: card-shove-1 |
| shout | grito de reação (impacto) | Casino: die-throw-1 + chips-collide-1 (mix) |
| hit | reação certa | Interface: confirmation_002 |
| miss | reação errada | Interface: error_006 |
| turn | sua vez (sininho) | Interface: glass_001 |
| win | vitória | Interface: confirmation_002 + confirmation_004, Casino: chips-stack-1 (mix) |
| tick / tock | tique-taque dos últimos segundos | Interface: tick_001 / tick_002 |
